# Gazoduc Invest

Application de gestion d'investissements et de suivi de portefeuille.

## Installation

### Backend
```bash
cd backend
npm install
npm start
```

### Frontend
```bash
cd frontend
npm install
npm run dev
```

## Configuration

Créez un fichier `.env` dans le dossier `frontend` avec :
```
VITE_API_URL=http://localhost:5001
```
